## Selected work

### 01 / UXPulse Analytics

**Understand where users get stuck.**

A self-hosted UX analytics platform connecting browser events to sessions,
conversion funnels, click heatmaps and form-friction signals. Its TypeScript SDK
captures structural form interactions without collecting entered field values.

[![UXPulse dashboard](https://raw.githubusercontent.com/JohanRos21/uxpulse-analytics/main/docs/screenshots/dashboard-overview.png)](https://github.com/JohanRos21/uxpulse-analytics)

`Next.js` `TypeScript` `FastAPI` `PostgreSQL`

[Explore the repository and architecture →](https://github.com/JohanRos21/uxpulse-analytics)

### 02 / LogGuard AI

**Turn application logs into signals worth investigating.**

A local-first monitoring prototype with log normalization, sequence analysis,
incident workflows and controlled model retraining. Redis and Celery support
asynchronous processing; project API keys separate access between projects.

[![LogGuard V3 dashboard](https://raw.githubusercontent.com/JohanRos21/logguard-ai/main/docs/images/LogGuard-Dashboard.png)](https://github.com/JohanRos21/logguard-ai)

`FastAPI` `PyTorch` `Next.js` `PostgreSQL` `Redis` `Celery`

[Explore the repository and architecture →](https://github.com/JohanRos21/logguard-ai)

<sub>Existing repository captures. LogGuard shows its V3 dashboard; displayed figures
describe the captured datasets, not guaranteed production results.</sub>

### 03 / Ticket Intelligence

**Classify support requests without making ML a single point of failure.**

A Node.js ticket API connected to a Spanish-language TF-IDF + Logistic Regression
classifier. Tickets retain category, confidence and model version. If the ML
service is unavailable, ticket creation continues with an explicit prediction status.

`Node.js` `Express` `FastAPI` `scikit-learn` `MySQL`

[Explore the implementation and evaluation →](https://github.com/JohanRos21/ticket-intelligence)
