## Selected work

### 01 / UXPulse Analytics

**Understand where users get stuck.**

Self-hosted product and UX analytics with a TypeScript SDK for event tracking,
sessions, funnels, click heatmaps and form-friction analysis. Privacy-focused
collection captures form interactions without entered field values.

`Next.js` `TypeScript` `FastAPI` `PostgreSQL`

[Explore the repository →](https://github.com/JohanRos21/uxpulse-analytics)

### 02 / LogGuard AI

**Turn application logs into signals worth investigating.**

A local-first log monitoring platform combining normalization, asynchronous
processing, ML sequence analysis and incident workflows, with project API keys
and controlled model retraining.

`FastAPI` `PostgreSQL` `Redis` `Celery` `Docker` `Next.js` `PyTorch`

[Explore the repository →](https://github.com/JohanRos21/logguard-ai)

### 03 / Ticket Intelligence

**Classify support requests without making ML a single point of failure.**

A support-ticket backend with Spanish-language classification, prediction
confidence and model traceability. A resilient fallback keeps ticket creation
available when the ML service is unavailable.

`Node.js` `Express` `FastAPI` `scikit-learn` `MySQL`

[Explore the repository →](https://github.com/JohanRos21/ticket-intelligence)
